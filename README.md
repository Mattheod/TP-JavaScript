# TP-JavaScript

## Présentation

Ce dépôt contient un TP réalisé dans le cadre de mon Bachelor Informatique à l'IPSSI Paris.
Ce projet a pour objectif de mettre en pratique les connaissances acquises au cours de ma formation, notamment en programmation JavaScript et en développement web.

## Technologies utilisées

* HTML5
* CSS3
* JavaScript (ES6+)

## Objectifs pédagogiques

* Découvrir et pratiquer les bases du langage JavaScript (variables, fonctions, conditions, boucles).
* Manipuler le DOM pour rendre une page web dynamique.
* Gérer les événements utilisateur (clics, saisies, formulaires).
* Structurer et organiser le code d'un projet web.
* Développer mes compétences en intégration et en programmation web.

Projet personnel à but pédagogique.
